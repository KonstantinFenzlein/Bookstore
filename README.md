# Bookstore

Kleine Online-Buchhandlung als Frontend-Übungsprojekt. Bücher stöbern, liken und kommentieren.

## Funktionen

- Darstellung der Bücher aus einer Datenliste
- Likes setzen und wieder entfernen
- Kommentare zu einzelnen Büchern hinzufügen

## Technologien

HTML5 · CSS3 · JavaScript (ohne Framework)

## Projekt starten

1. Repository klonen: `git clone https://github.com/KonstantinFenzlein/Bookstore.git`
2. `index.html` im Browser öffnen – keine Installation nötig.
